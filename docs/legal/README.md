# Legal and policy documents

These documents describe what ResearchPilot AI **actually does** with data, based on the code in this
repository. They are **templates for an operator to complete**, not legal advice, and none of them
claims that any law or standard is satisfied.

* Text written as `[OPERATOR: ...]` is a placeholder. The person or organisation that runs a
  deployment must replace each one with a real decision (name, contact address, jurisdiction,
  effective date, retention periods, and so on). The in-app pages highlight unfilled placeholders so
  they are not missed.
* Nothing here invents a company, address, registration, certification, or compliance status.
* Before offering the service to anyone other than yourself, have a qualified lawyer review these
  documents against the laws that apply to you and your users (for example data-protection and
  consumer law). Each document ends with a list of points that need that review.
* The same files are shown in the application at `/legal`.
