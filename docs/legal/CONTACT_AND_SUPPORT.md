## Before you write
* **Run failed:** open the run page; it states the reason and often offers **Resume from saved
  progress**. Typical causes are a missing or exhausted API key, a provider outage, or a call budget.
* **Cannot sign in or verify email:** use "Forgot password"; check the spam folder.
* **Data export or deletion:** Settings > Privacy and data.
* **Something wrong in a report:** open the cited source; report factual errors in sources to that
  source's publisher.

When writing to support include the project or run identifier shown in the address bar, the time, and
what you expected to happen. Never send your password or API keys.
